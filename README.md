# FLATS_n_BEYOND_pro

Luxury Real Estate Advisory & Curated Secondary Market Platform prototype for **Flats n Beyond** (Gurgaon / Delhi NCR).

---

## 🌟 Key Features

- **🏠 Openhouse-Style Property Detail Page**:
  - Interactive multi-image gallery with vertical thumbnails.
  - Dimension specs, verified score metrics, sunlight ratings, and 3D architectural floor plans.
  - Direct advisory and callback scheduling.

- **🔍 Smart Search & Categorized Listings**:
  - Micro-market search across Golf Course Extension, Dwarka Expressway, SPR, and DLF Mansions.
  - Filter categories: *Fresh Bookings / New Launches*, *Resale / Secondary Market*, and *Sale & Purchase*.
  - 12 verified high-res luxury property listings with distinct galleries.

- **🎨 Turnkey Interior Design Showcase**:
  - Interactive interior concept cards with custom lighting, acoustic veneer, and marble detailing.

- **📄 Dedicated Legal & Advisory Pages**:
  - **About Us**: Company overview, vision, mission, and core values.
  - **Contact Us**: Interactive inquiry form, headquarters location map, branch offices, and expandable FAQ.
  - **Privacy Policy & Terms**: Complete institutional legal frameworks.

- **⚡ Performance & Visual Excellence**:
  - Optimized local imagery (compressed & responsive).
  - Modern typography and warm luxury champagne & gold color palette.

---

## 🛠️ Tech Stack

- **React 18** (Vite)
- **Lucide Icons**
- **Vanilla CSS / Custom Design System**

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
